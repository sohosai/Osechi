# Osechi

雙峰祭のために開発中の映像スイッチング/伝送ソフトウエア

## コンセプト
Osechiは、一般的なスペックのPCでも安定して動作する、軽量で扱いやすい映像スイッチング・伝送ソフトウエアを目指しています。

従来のOBSなどの代替となる安定性を備えるとともに、独自の軽量な通信プロトコルを実装することで、LAN内での手軽で低遅延な映像伝送を実現します。

また、特定のOSに依存しないマルチプラットフォーム設計により、幅広い環境で柔軟に運用できるよう開発されています。

詳しくは[ロードマップ](docs/roadmap.md)を参照してください。

## 開発環境

本プロジェクトの開発には **Rust 1.9.5以上** が必要です。高速化の設定については、[高速なビルドに関する情報](docs/fast-build.md) を参照してください。
